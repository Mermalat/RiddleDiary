# Riddle Diary

*Some pages wait patiently. This one answers.*

## Awaken the ink

1. Open **Settings → Riddle Diary**.
2. Choose **Anthropic (Claude)** or **OpenAI (Codex)** and enter that provider's API key. On desktop you can instead choose **Codex CLI**, **Claude Code**, or **Gemini CLI**, using the login you already completed in your terminal. For Codex, run `codex login` and sign in with ChatGPT first. Leave the CLI model empty and use **Check installation**.
3. Set **Diary name** to whatever you like (for example, `cupcake`). Enable **Ink effect** for gradual writing and a soft fade.
4. Return to this note. Write a new line at the bottom, end it with `../`, and press **Enter**.
5. Watch your question become bold and the placeholder become the reply. Keep writing below the closing rule.

You can also use the command palette: **Riddle Diary: Diary: reply now**. **Escape** cancels a reply while the editor is focused.

**No API key yet?** Run **Riddle Diary: Diary: preview ink (offline)** to watch a clearly marked sample stream into the note. This preview sends nothing to a provider and is excluded from assistant history.
